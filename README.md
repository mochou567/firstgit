# firstgit

my first repository

## 说明

这是一个用于学习 Git 与 GitHub 基本工作流的练习仓库。

## 快速开始

```bash
git clone git@github.com:mochou567/firstgit.git
cd firstgit
```

## 常用命令

```bash
git status              # 查看当前改动
git add <文件>          # 暂存改动
git commit -m "说明"    # 提交
git push                # 推送到 GitHub
```
